# Frontend Supabase Setup

1) Create `.env` from `.env.example` and set:
   - REACT_APP_SUPABASE_URL
   - REACT_APP_SUPABASE_ANON_KEY
   - REACT_APP_API_BASE_URL (backend)
   - REACT_APP_SITE_URL (used for auth redirects)

2) In the Supabase Dashboard:
   - Authentication > URL Configuration:
     - Site URL: set to your app domain (or http://localhost:3000 for dev)
     - Add redirect allowlist:
       - http://localhost:3000/**
       - https://yourapp.com/**

3) Start the app:
   - npm install
   - npm start

The app reads env via `src/config.js` and initializes the Supabase client in `src/lib/supabaseClient.js`.
